# Dog Curve
```cpp
omega = 0;
while(!goal_reached()) {
	if(goal_heading() - robot_heading > thresh) {
		omega++;
	}
	else if(goal_heading() - robot_heading < -thresh) {
		omega--;
	}
	else {
		omega = 0;
	}
	VWSetSpeed(v, omega);
}

int goal_reached() {
	return abs(robot_x - goal_x) + abs(robot_y - goal_y) < eps;
}

int goal_heading() {
	return atan2(goal_y - robot_y, goal_x - robot_x);
}
```

# Spline Curve
- Hermite Splines
	- Robot position $p_{k}$
	- Robot heading $Dp_{k}$
	- Destination position $p_{k+1}$
	- Destination orientation $Dp_{k+1}$
- $u$ runs from [0...1] start to finish motion
$$H_{1}(u) = 2u^{3}-3u^{2}+1$$
$$H_{2}(u) = -2u^{3}+3u^{2}$$
$$H_{3}(u) = u^{3}-2u^{2}+ u$$
$$H_{4}(u) = u^{3}- u^{2}$$
```cpp
//start = a, goal = b
sp(u) = H_1(u)a + H_2(u)b + H_3(u)D_a + H_4(u)D_b
```

```python
a = [0,0,0]
b = [x,y,alpha]
len = 2*sqrt(x**2 + y**2)
u = 0.0

def init():
	ax = 0
	ay = 0
	Dax = len #vector for 0
	Day = 0   #vector for 0
	#goal ---------------------
	bx = x
	by = y
	Dbx = len * cos(alpha)
	Dby = len * sin(alpha)
	
while (u <= 1.0):
	H1 = 2*u**3 - 3*u**2 + 1
	H2 = -2*u**3 + 3*u**2

	H4 = u**3 - u**2
	
	sp_x = H1*ax + H2*bx + H3*Dax + H4*Dbx
	sp_y = H1*ay + H2*by + H3*Day + H4*Dby
	
	u += 0.1
```

# What about obstacles?

## Local Control for Obstacle Avoidance
- Focus: reactive/short-horizon planning methods
- Used after global path planning
- Operate on local sensor information
- Goal: maintain progress to goal while avoiding obstacles
- Common in mobile robots, drones and autonomous vehicles

## Dynamic Window Approach (DWA)
- Velocity-space local planner
	- Search performed in velocity space $(v, \omega)$
	- Only dynamically reachable velocities considered
	- Each sampled velocity generates a short simulated trajectory
	- Trajectories scored based on safety and goal progress
	- Best trajectory determines next velocity command
- Samples feasible linear and angular velocities
- Considers robot dynamic limits
- Evaluates trajectories over short horizon
- Selects velocity command with highest score
![[Pasted image 20260318123804.png]]
## Time Elastic Band (TEB)
- Optimisation based local trajectory planner
- Represents trajectory as sequence of poses with time intervals
- Trajectory behaves like an elastic band that deforms around obstacles
- Simultaneously optimises spatial path and timing
- Handles non-holonomic constraints
![[Pasted image 20260318124101.png]]
- Path represented as nodes connected by virtual springs
- Obstacle constraints push nodes away from collisions
- Temporal constraints adjust timing between nodes
- Optimisation continuously reshapes trajectory
- Produces smooth and dynamically feasible paths
![[Pasted image 20260318124203.png|413]]
- Trajectory is continuously re-optimised
- Handles dynamic obstacles
- Supports differential drive and car-like robots
- Constraints include:
	- Velocity limits, acceleration limits, obstacle clearance

## Artificial Potential Fields (APF)
- Treat goal as attractive potential
- Treat obstacles as repulsive
- Robot follows negative gradient of total potential field
- Very computationally efficient
- Easy to implement and visualise
![[Pasted image 20260318124431.png]]
- Common issue: local minima where forces cancel
	- Can trap robot
- Oscillations in narrow passages
- Requires careful tuning of gains
- Extensions include navigation functions and random escape methods
## Vector Field Histogram (VFH)
- Histogram based obstacle avoidance
- Builds polar histogram of obstacle density around robot
- Identifies candidate steering directions
- Selects safest direction closest to goal heading
- Works well with range sensors like LiDAR
- Pipeline:
1. Build occupancy grid from sensor data
2. Convert grid to polar histogram
3. Apply smoothing and thresholding
4. Identify free steering sectors
5. Select direction toward goal
## Model Predictive Control (MPC)
- Optimisation based control method
- Predicts future robot states over finite horizon
- Minimises cost function subject to constraints
- Can incorporate dynamics, obstacles and actuator limits
- Receding horizon: optimisation repeated at each timestep
1. Predict future states over horizon `N`
2. Evaluate cost for control sequences
3. Select optimal first control input
4. Shift horizon forward at next timestep
5. Allows constraint handling and dynamic feasibility

## Model Predictive Path Integral (MPPI)
- Sampling based variant of MPC
- Generates many stochastic control rollouts
- Evaluates trajectories using cost function
- Weights trajectories using path integral formulation
- Well suited for nonlinear and complex systems

# Comparison of Local planners
- DWA: fast, velocity based, widely used
- TEB: trajectory optimisation with timing
- APF: simple but prone to local minima
- VFH: reactive steering from obstacle histogram
- MPC/MPPI: optimisation based, high performance but computationally heavier
