## Image Data Types
- 2D array
	- Binary image: 0 for white, 1 for black
	- Grayscale: 1 byte per pixel: 0 black to 255 white
	- Colour: 3 bytes per pixel
		- RGB - changes with lighting conditions
		- HSI - takes into account different lighting saturations
			- Max and min of 3 colours, then following formula to find hue
			- Hue must be in desired range
			- Intensity must be above threshold because of low-light hue problems (hue almost arbitrary at low-light)
	- Image file types:
		- PBM - binary
		- PGM - grey
		- PPM - colour

# Image Processing Functions
- Point operators for each pixel
	- Same operation for every pixel, used for HSI conversion, can be ideally parallelised
	- Used for threshold to binary conversion
- Local operators
	- Pixels in neighbourhood
	- Mean value
	- Good parallelisation
	- Should use separation  (do parallel x and in y directions)
	- Noise reduction
		- Remove all white or black pixels
		- Median filter - tends to be better than mean
- Edge detection
	- Identify object outlines in image by finding greyscale discontinuities
	- Works most of the time but not always, such as in cases with high shadows
	- Can't go to the edges of the image, have to deal with them (set to zero, keep original value etc)
	- Gives us edges, hopefully an outline

- Skeletonization
	- Reduce objects in binary image to single pixel outline
	- Remove pixels based on conditions
	- `code`
- Morphological Operators
	- Cleaning up object borders by removing or adding (erosion or dilation)
	- `code`
	- Open and close - erode to get rid of noise and then dilate again to get strong lines
- Segmentation
	- Dividing into coherent regions, hopefully objects
	- Similar greyscale values belong to same physical object in image
	- Using region growing with equidistant seed points placed all over the image
	- Modern neural networks such as SegNet
- Corner detection
	- Find end-points of edges
	- Edge pixels with high curvature
		- When the normal of an edge changes direction
		- Change in gradient of the normal
	- Easily tell how far things are moving using the corners as points of interest
- Hough
	- Brute force method of finding lines
	- For every black image point add entries in accumulator for matching lines going through this point
	- Put lines into Hough table, the points in the table with the highest values are lines
		- Give angle and distance from origin
- Stereo
	- Analysis of binocular stereo pair of images
	- Identify interest points in both images
	- Match interest points
	- Displacement of matching point pair is spatial distance
	- Simpler: parallel cameras, calibration, epipolar lines
		- Reduce search to single line
	- Computationally expensive as needs to identify points of interest
	- Anaglyph is fancy name for 3D glasses
- Motion Stereo
	- Camera taking a photo and then another some defined time later while it is moving
- Image sequences
	- Take 2 images over time lapse, take absolute distance
- Optical flow
	- Motion analysis for image sequences
	- Movement of points between frames
- Colour detection
	- Uniquely coloured objects
	- Find hue usually in a range, mark as 1 if true
	- Histogram to find where the blob exists
		- Max x and y values
	- `code`
- From image to world coordinates
	- From image to robot local coordinates, then to global coordinates
	- `[i, j] -> [x', y'] -> [x, y]`
	- Known size object, you can calibrate in multiple places using proportionality factor
		- $x' = k \times \frac{d}{i}, y' = k \times \frac{d}{j}$
