# Differential Drive
## Forward
- Simplify as unicycle
- $v, \omega, x, y, \psi$
![[Pasted image 20260429101218.png]]
- How do we get them?
	- $s=2\pi r | r = \text{radius of wheel}$
	- $v=2\pi r \theta|\theta = \text{rot wheel speed}$
- Vehicle origin is midpoint between wheels $d$ is the distance between left and right wheels (between $s_{R}$ and $s_{L}$)
- $tan\psi = (\frac{s_{R} - s_{L}}{d})$
	- Get rid of tan because we are driving in an arc
- $\Delta s = (s_{L}+s_{R})/2$
	- $s_{L} = 2\pi r ticks_L/ticksPerRev$

# Ackermann
## Forward
- Simplify as bicycle model
- Vehicle origin is the midpoint between driven wheels
- $e$ is the distance between the front and back wheels
- $\alpha$ is the steering angle
- $sin\alpha = down/s$
- $cos\alpha = forward/s$
- $\Delta\psi = \frac{down}{e}= sin\alpha \times s/e$
- $\omega = sin\alpha \times v/e$
- $\Delta\phi [rad] = sin\alpha . \frac{s}{e}$ 
- $\Delta s [m] = \frac{s_{L}+s_{R}}{2}$

### Dog Curve
``` python
omega = 0

def goal_reached():
	return abs(robot_x - goal_x) + abs(robot_y - goal_y) < eps

def goal_heading():
	return atan2(goal_y - robot_y, goal_x - robot_x)

while not goal_reached():
	if (goal_heading() - robot_heading > thresh):
		omega += 1
	else if (goal_heading() - robot_heading < -thresh):
		omega -= 1
	else:
		omega = 0
	VWSetSpeed(v, omega) #linspeed, angspeed
```

# Obstacle Avoidance
### Local Control
- Focus: reactive/short-horizon planning planning methods
- Used after global path planning
- Operate on local sensor information (LiDAR, depth, radar)
- Goal: maintain progress to goal while avoiding obstacles
- Common in mobile robots
### Dynamic Window Approach (DWA)
- Velocity space local planner
	- Search performed in velocity space ($v$, $\omega$)
	- Only dynamically reachable velocities considered
	- Each sample generates a short simulated trajectory
	- Trajectory scored based on safety and goal progress
	- Best trajectory determines next velocity command
- Samples feasible linear and angular velocities
- Considers robot dynamic limits
- Evaluates trajectories over a short horizon
- Selects velocity command with highest score
- Objective function often includes:
	- Distance to obstacles
	- Progress toward goal
	- Alignment with global path
	- Velocity preference (move faster when safe)
### Time Elastic Band (TEB)
- Optimisation based local trajectory planner
- Represents trajectory as sequence of poses with time intervals
- Trajectory behaves like an elastic band that deforms around obstacles
- Simultaneously optimises spatial path and timing
- Handles non-holonomic constraints
![[Pasted image 20260429105049.png]]
- Trajectory continuously re-optimised
- Handles dynamic obstacles
- Supports diff drive and car-like robots
- Constraints:
	- Velocity limits
	- Acceleration limits
	- Obstacle clearance
