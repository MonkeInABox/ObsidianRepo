# Localisation Methods
1. Proprioceptive Sensors (internal sensors)
	1. Shaft encoders
	2. Accelerometers
	3. Gyroscopes
	4. Inclinometers
	5. Inertial Measurement Units (IMU)
2. Exteroceptive Sensors (external sensors)
	1. Satellite GPS receiver
	2. Magnetic compass
	3. LiDAR
	4. Radar
	5. Infrared Sensors
	6. Camera
	7. Radio beacon detectors

## Based on Proprioceptive
- Use internal sensors to determine robots movements
- Use integration of movement data to find robot's new position (dead reckoning)

## Based on Exteroceptive
- Passive sensors: GNSS, compass, camera, radio beacon
- Active sensors: LiDAR, radar, infrared sensors
- Global positioning sensors: give absolute position directly (satellite GNSS, global sonar, beacons)
- Local positioning sensors: need to calculate/estimate position from map data (LiDAR, radar, infrared, camera)

# Visual Odometry/Visual Navigation
- Store hundreds/thousands of key images from a known environment, each with the exact position (pose) data
- For a new image (or a short sequence) taken from a robot at an unknown location within this area, use stochastic methods on image features to find the correct robot locations

# Coordinate Systems
- Distinguish
	- World coordinates (global)
	- Robot coordinates (local)
- Robot is at global position $[r_{x}, r_{y}]$, global orientation $\psi$ , senses an object at local coordinates $[o_{x'}, o_{y'}]$
- Calculation of global object coordinates $$[o_{x}, o_{y}] = Trans(r_{x}, r_{y})Rot(\psi)[o_{x'}, o_{y'}]$$

# Dead Reckoning
- Use internal sensors (odometry, distance sensors, inertial sensors) to sense robot movement
- Continuously update robots pose using integration, based on these measurements
- Big problem: drift - position/orientation will get more and more inaccurate over time
- Every segment of path has a rotation and a translation
- Transform every segment into one homogeneous 3x3 matrix $T_{i-1,i}$ $$T_{0,n}=T_{0,1}\times T_{1,2}\times ... \times T_{n-1,n}$$

- Dead reckoning only works over small distances
- Once the angular error has reached $90deg$ the result is meaningless

# Global Positioning Systems
## Pros
- Gives us correct global position straight away
- No calculations required
- No drift
- Can be based on sonar, beacons (indoor) or radar (outdoors)
- Can be satellite based - GNSS = Global Navigation Satellite System
## Cons
- Large setup cost (huge for satellite based)
- GNSS are not available indoors or under water
- GNSS reception problems near high-rise buildings
- All localisation will stop if GNSS outage
- Random walk problem

# Probabilistic Methods
- If a global positioning system is not available, what can we do to minimise spatial uncertainty
- Kalman filter: optimal linear mean-square error estimator, recursive
- Extended Kalman filter: linear recursive estimator for systems described by non-linear models
- Particle filter: draw random samples, predict through non-linear model, update likelihood, define distribution, resample
