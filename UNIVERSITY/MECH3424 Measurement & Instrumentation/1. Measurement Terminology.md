# Input/Output
- The dependent variable is the variable that is manipulated in an experiment. It remains unchanged between conditions being observed in an experiment. This is the presumed case (x-axis)
- The dependent variable is the variable that is believed to change in the presence of the independent variable. it is the presumed effect (y-axis)
# Static and Dynamic
- Measured data comes from sensors. Sensor characteristics are defined as either static or dynamic.
- **Static**: calibration, resolution, accuracy, threshold, offset, drift, hysteresis, sensitivity, reproducibility and repeatability
	- Static implies the system has reached steady state, whenever an instrument state has changed (because the input has changed) you need to consider if enough time has elapsed to ensure the instrument has reached a steady state, allowing a static measurement characteristic to be defined
- **Dynamic**: response time, warm-up time, frequency response, cutoff frequency, noise
# True Value, Accuracy and Trueness
- The **true value** of a measurement cannot be absolutely determined - it is a theoretical concept and in general cannot be known exactly. Instead an accepted reference value is used (often a calibration standard). This reference value can be determined by:
	- A theoretical or established value, based on scientific principles
	- An assigned or certified value (standard)
	- A consensus or certified value (from a scientific or technical group)
	- The expectation (mean) when the previous are not available
- **Accuracy** is the closeness in agreement between a test result or measured value and the true value.
	- In practice, the accepted reference value is substituted for the true value
	- The term accuracy when applied to a set of test or measurement results, involves a combination of random components and a common systematic error or bias component
	- Accuracy refers to a combination of trueness and precision
- The **trueness** is the closeness of agreement between the expectation of a test result or a measurement result and a true value
	- The measurement of trueness is usually expressed in terms of bias
	- Trueness is sometimes referred to as accuracy of the mean. This usage is not recommended
	- In practice, the accepted reference value is substituted for the true value
# Bias and Errors
- Trueness is a qualitative indicator of the closeness of agreement between the average value obtained from a large series of test results to an accepted true (calibration). Trueness applies to the average value of a large number of measurements.
- Bias, also called Offset, is the quantitative difference between the expectation of a test result or measurement result and a true value
	- Bias is the total systematic error as contrasted to random error

- **Systematic error** is equivalent to bias and shifts the mean value in a predictable way over a number of measurements. Systematic error can be corrected only when the true value is known
- **Random error** occurs over the course of a number of measurements, and causes the results to vary in an unpredictable way. It is not possible to correct for random error
# Precision
- Precision is the closeness between independent measurements of a quantity under the same conditions
	- Precision depends only on the distribution of random errors and does not relate to the true value or the accepted value
	- The measure of precision is usually expressed in terms of imprecision and computed as a standard deviation of the test results or measurement results. Less precision is reflected by a larger standard deviation 
	- Quantitative measures of precision depend critically on the stipulated conditions (such as repeatability and reproducibility - see later)

# Bias and Precision 
- **Bias** is an error associated with the instrument and can be (and should be) removed by calibration. The bias is traditionally referred to as **systematic error**. More recently, the Guide to Measurement Uncertainty uses the term **Type B uncertainty**. This is because while they can be removed, the bias error will be different for each instrument and can therefore be classed as a random uncertainty
- However **precision** is an error associated with random processes outside of the control of the instrument/operator. These random sources of variation in the data cannot be removed and must be quantified by placing numerical uncertainties on the data ($\pm$), The definition of precision described here is overly simplistic and we will refine this in later lectures
- The accuracy of an instrument (the better term to use uncertainty) includes a combined effect of:
	- Part to part variations
	- Linearity
	- Hysteresis
	- Dead band
	- Calibration
	- Repeatability errors
	- Reproducibility
- Accuracy is used to specify the worst-case performance of the system. More recently, accuracy has been replaced by the term uncertainty $u$. 
- The precision rating may be represented as either:
	- A measured value
	- A percent of input span (full scale)
	- In terms of output signal
# Scatter in the Data = Statistical Uncertainty
- **Precise ~ lack of scatter** (says nothing about trueness)
- **True ~ lack of systematic error** (says nothing about precision)
# Importance of Calibration
- Instrument calibration is one of the primary processes used to maintain instrument accuracy
- Calibration involves the comparison an instruments measurements to a known standard and creating a relationship between the two
- **Calibration rule-of-thumb**: when calibrating an instrument the test equipment should be at least 4 times as accurate as the instrument under test. For example, precision weights are used to define the weights of scales and dumbbells
- Calibration allows the best estimate of the true measurement to be made. Note that the true value can NEVER be found, only estimated. A calibration is typically performed by taking measurements over the expected measurement range and fitting the data to find the relationship. Assuming a LINEAR relationship is found, an estimate of the true value (calibrated value) might be:
$$y_{i}=mx_{i}+b$$

# Full Scale Output
- **FSO** is the absolute maximum output measured with maximum (absolute) input stimulus applied ($|x_{max}|$). This must include all deviations from the ideal transfer function. In this figure, an offset of $\Delta$ results in a larger FSO than one would expect for a perfect input/output relationship
- **Full-scale Span FSS** is the difference between the output at maximum rated input and the output at minimum input or equivalently the change in output possible over the operating range. Any constant offset $\Delta$ in the instrument therefore has no effect on FSS.
# Linearity
- It is normally desirable that the output reading of an instrument is linearly proportional to the quantity being measured
- This is achieved by plotting the measured output (Y) against some independent variable $x_i$ that the sensor measures. For example, for MEMS pressure sensors, the output is voltage and the input quantify is pressure. Two different methods can be used to describe this linearity:
	- End Point Linearity: Plot a straight line on the graph of X-Y from the zeros data point ($y_0$) to the full scale output ($FSO = y_n$) data point
	- Linearity can also be defined by a line of best fit: numerical methods use data from all the points and attempt to minimise the mean-squared error, from the line of best fit to all data point using a Least Squares Best Fit Straight Line
- Subsequently in both methods, the data point which deviates most ($\Delta$ $y$) from the simple straight line is used to specify the linearity of the transducer as a $\pm \%$ of the full scale span $\%FSS(y_{n}-y_{0})$. Note we need the $\pm$ to account for the spread
## End Point Method
- Plot a straight line on the graph from $y_0$ to $y_n$ 
- Find the data point which deviates most ($\Delta y$) from the simple straight line
- Express as a $\pm \%$ of the full scale span $\% FSS (y_n - y_0)$ 
- **Problem**: any errors associated with the end point data cause the slope of the line to change dramatically
	- Better applied to data that has some deterministic (repeatable) trend such as calibration that is non linear as shown below
## Least Squares
- To overcome this problem, we can try to chose a better line using a process called "the line of best fit"
- Line of best fit is chosen to minimise the distance from the line to all the points
- This can be done by eye
# Sensitivity
- The sensitivity of a measurement is a measure of the change in instrument output that occurs when the quantity being measured changes by a given amount. Thus, sensitivity.
$$slope = \frac{dy}{dx}= sensitivity=\frac{sensorOutput}{measureAndProducingOutput}$$
- For a straight line fit, sensitivity is the slope or derivative of the data
- A constant value for sensitivity assumes the instrument produces a linear output change with the quantity being measured

# Drift
- Variations can occur in the ambient conditions that affect certain static instrument characteristics. These changes are represented in manufactured data as:
	- Zero (bias) drift: the zero reading of an instrument is changed by the ambient conditions resulting in a constant error over the full range of measurement. Zero drift is normally removable by calibration before each measurement. Examples: a sensor with voltage output may have a static voltage shift of $V_{zd}$ volts/C, called a zero drift coefficient
	- Sensitivity drift (scale factor drift): the amount the instrument's sensitivity varies as ambient conditions change, and is given by sensitivity drift coefficient. Sensitivity drift is measured in units of the form $slope/C$ 
	- An instrument may suffer from both zero drift and sensitivity drift at the same time

# Dead Space
- Dead space, dead zone or dead-band is defined as the range of different input values over which there is no change in output value. Any instrument that exhibits hysteresis also displays dead space, but hysteresis is not a requirement for an instrument to exhibit a dead space. The deathband may not be zero.

# Resolution & Threshold
- **Resolution** refers to the smallest change in the input quantity that will produce a measurable change in the output signal
	- A finite resolution exists in all systems, analogue or digital and the specification is valid across the entire full scan range of the instrument
- **Threshold**, sensitivity limit or limit of detection (LOD) are used to describe the smallest input quantity (around $x=0$) that can cause a measurable change in the output of an instrument. The threshold is defined as being the first noticeable change that can be detected
# Decibel Scale
- The decibel (dB) of a dimensionless amplitude is defined as $20log_{10}(\frac{A_{1}}{A_{ref}})$ or noting that Power $P = kA^{2}$
- The dB of a dimensionless power is defined as $10log_{10}(\frac{P_{1}}{P_{ref}})$
- The dynamic range is the ratio of the largest to the smallest input that an instrument can faithfully measure, thus a 60dB range indicates the instrument can handle a range of powers of $10^{6}$ or an amplitude range of $1-1000$

# Noise Floor
- When an instrument is improved to the point where the threshold becomes closer and closer to zero, we eventually hit a lower limit on what can be measured due to random fluctuations. This limit is the noise floor
# Repeatability and Reproducibility
- Total process variation consists of part to part variation plus measurement system variation. Measurement system variation consists of:
	- **Repeatability** - where a variation is observed when the same measurement is performed using the same equipment, laboratory and operator
	- **Reproducibility** - where a variation is observed when the same measurement is performed using different equipment, laboratory and operator
	- **Precision** - or measurement variation is caused by both repeatability and reproducibility
# Dynamic Measurement Systems
## Zeroth Order System
- A zero order instrument has a characteristic defined by $y=Kx$ 
	- Where: $y = outputQuantity, x = inputQuantity, K=staticSensitivity$
- This represents ideal or perfect dynamic performance. In practice, systems are typically linear over only a small finite range
![[Pasted image 20260720155204.png]]
## First Order System
$$\frac{a_{1}dy}{dt}+a_{0}y=b_{0}x\to\frac{a_{1}dy}{a_{0}dt}+a_{0}y=\frac{b_{0}}{a_{0}}x$$
- $\tau$ is $\frac{a_{1}}{a_{0}}$, the time constant
- $K$ is $\frac{b_{0}}{a_{0}}$, the static sensitivity
$$\tau \frac{dy}{dt}+y = Kx \to (\tau D+1)y = Kx$$
- $D$ is the differential operator
$$\frac{output}{input}=\frac{y}{x}=\frac{K}{\tau D+1}$$
