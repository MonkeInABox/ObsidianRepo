# Unbalance Measurement (Ballast)
- Strain gage: $\frac{\delta R}{R_{0}} = S\epsilon$ 
- The simplest measurement would be to measure the output across a voltage divider (ballast or potentiometer)
$$V_{0}=\frac{R_{g}}{R_{g}+ R_{b}}V_{S}=VoltageDivider|R_{g}= R_{0}+\delta R$$
- Assuming $\delta R << R_{0}$, and output max when $R_{0}= R_{b}$:
$$V_{0}=\frac{1}{2}V_{s}+\frac{S\epsilon}{2}V_{S}$$
$$V_{0}+\delta V = (\frac{1+S\epsilon}{2})\frac{V_{s}}{2}$$
- Common mode signal (DC) = $\frac{V_{s}}{2}$
- Issues: 
	- $V_{0}$ responds to total resistance $R_{0}+ \delta R$ and not the change in resistance $\delta R$, since $\frac{\delta R}{R_{0}}<4\%$ sensitivity is low
	- Non-linear output at large strains
	- Temperature affects strain gage and $R_b$ 
	- Supply voltage noise directly affects measurement

# Balanced Bridges = Wheatstone Bridge
- A bridge is a circuit having 4 connected arms
- A bridge is balanced when measured output is voltage is zero $0V$ 
- Used for measuring small changes in resistance $\delta R$ in one or more bridge resistances
- Assume meter impedence $>> R_{1}//R_{2}+ R_{3}//R_{4}$
$$V_{0}=\frac{(R_{2}R_{3}-R_{4}R_{1})V_{S}}{(R_{1}+R_{2})(R_{3}+ R_{4})}$$
- When $\frac{R_{2}R_{3}}{R_{4}R_{1}}=1$ bridge is balanced
- Assume all 4 resistances have the same average value $R_{0}$, but that a small perturbation exists on each resistance $R_{i}\to R_{0}+\Delta R_{i}$

# Common Mode Noise
- Differential Mode Signals:
	- ![[Pasted image 20260804122440.png]]
	- No current flows to ground because of symmetry of V1 and V2 about ground. All differential mode current $I_{D}$ flows through load$$V_{d}=(V_{1}-V_{2})$$
	- Do not directly generate interference in unshielded twisted pair cable systems
	- ![[Pasted image 20260804122631.png]]
- Common Mode Signals:
	- ![[Pasted image 20260804122649.png]]
	- No current flows in the load (no pot difference)
	- All common mode current $I_C$ flows to $GND$ via parasitic capacitance between the cable and $GND$ $$V_{C}=\frac{V_{1}+V_{2}}{2}$$
	- Directly generate interference in unshielded twisted pair cable systems
	- ![[Pasted image 20260804122815.png]]
### Common Mode rejection Ratio
$$CMRR = V_{C}/V_{d}$$
- In decibel it is referred to as the CMR $$CMR = 20log_{10}(V_{C}/V_{d})$$

- If CMR=80db: A $V_C = 50V$ means that $V_{d}=50/10^\frac{80}{20}=5mV$  
# Signal to Noise Ratio
- SNR is a dimensionless quantity used to express the ratio of signal power to noise power $$SNR=\frac{S}{N}=\frac{P}{\sigma^{2}}=\frac{A^{2}_{rms}}{\sigma^{2}}$$
![[Pasted image 20260804123050.png]]
$$SNR = \frac{S}{N}=\frac{A^{2}}{2\sigma^{2}}$$
- If the noise is gaussian, zero mean and is defined over a bandwidth of B, then $\sigma^{2}=\eta B$ $$SNR=\frac{A^{2}}{2\eta B}$$
- Because SNR is dimensionless, it is sometimes on dB:$$SNR_{dB} =10log_{10}\frac{S}{N}dB$$

# Getting Rid of Noise
- Differential amplifiers remove common mode noise, that is by taking the difference of the two wires the “common” signal is removed.
![[Pasted image 20260804123814.png]]
- Twisted pair cables carrying differential signals do not radiate magnetic-field noise (interference) since the alternative twists generate + and –ve radiating fields which cancel. In the same way, the twisted pairs do not pick up much magnetic-field interference since the twists result in (on average) zero summed signal in the wire.
![[Pasted image 20260804123850.png]]
- If the twisted pair wires both have a common signal on them (say both wires carry DC 2.5 v), then relative to ground (somewhere in the system) the wires can radiate electric-field noise (drawn as a little capacitor in the circuit). Often the case of the box is ground so the  noise can couple to the box and then back into other parts of the circuit. The solution here is to shield the cables (cover the twisted pairs in a conductive foil layer) and this stops electric fields (the shield does not stop magnetic fields but the twisted pairs reduce this source of noise)
