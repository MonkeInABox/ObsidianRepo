# Noiseless Systems $n(t) = 0$
- Any system can be represented by a black box in the time or frequency domain
- In time, the system is characterised by response $h(t)$ which describes how the output $y(t)$ changes in response to an input $x(t)$ - given by the convolution $y(t) = x(t) * h(t)$
- In frequency, the system is characterised by the transfer function (frequency response) $H(f)$ whcih describes how the output spectrum $Y(f)$ changes in response to an input spectrum $X(f)$ - given by the multiplication $Y(f) = H(f)X(f)$ so that $H(f) = \frac{Y(f)}{X(f)}$
- These two descriptions are related by the Fourier transform
