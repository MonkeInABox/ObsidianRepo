# Graph Terminology
- Axes: minimum of 2 axes, x-axis and y-axis. A secondary y-axis may be present
- Axis label/title: name (and unit) to describe the dependent or independent variable for the dataset being plotted
- Category Label: Used to denote the name of a category or a group of data and may be descriptive or  range of numeric values
- Axis scale: can either be linear or logarithmic typically but can be any function
- Ticks: small marks aligned to the numbering on each axis to indicate the exact position of the number on the axis

## Types of Data
- Ordinal: similar to categorical, exceept a clear ordering to the variables (low income, middle income, high income)
- Categorical: data falls into one of two or more discrete categories, no intrinsic ordering
- Interval: both an order and an equal spacing (temperature)
## Presentation
- Measured data is always shown as a point (marker), never a line
- Models or simulations are generally shown as lines
- If colour, ensure readable when printed in grey scale - use solid, dashed and dotted lines for points to make them distinguishable
- Avoid a legend, label the data directly
- When axis unreasonably large of small, mark the ast scale division with the multiplying factor
- Images NEED scale bars

# Tables
## Good Tables
- Make it easy for your audience to find and understand numbers within your tables
- Design both the layout and the labelling of your tables in a straightforward and unobtrusive manner, so the attention is on the key points to be conveyed by your data, rather than on the structure of the table
- Tables should be able to stand alone. Each table should contain enough  metadata to allow it to be copied and pasted into another document and still make sense
- Column headers should include any relevant metadata (e.g. units, time, area)
- Avoid unnecessary text
- Display data by chronological order or using some standard classification
- Use a minimum of decimal places
- Thousand seperators ( can avoid issues that , causes between languages)
- Align numbers on the decimal point (or to the right)
- Do not leave a cell empty, should have not available or not applicable
# Legend
- Should identify the symbols, patterns or colours used to represent the data in the chart
- Should not be displayed when only one series
- Use labels rather than a legend if possible

# Significant Figures/Digits
- Non-zero digits within the given measurement or reporting resolution are significant
- Zeros between two significant non-zero digits are significant
- Zeros to the left of the first non-zero digit are NOT significant
- Zeros to the right of the last non-zero digit in a number with a decimarl point are significant if they are within the measurement or reporting resolution
- Spurious digits, introduced by calculations resulting in a number with a greater precision than the precision of the used data in the calculations should not be used
- The term reliable is used, if $N$ are significant, then the first $(N-1)$ digits are considered reliable
# Bar and Column Charts
- Column and bar charts are useful for comparisons
- Column:
	- Data changing over time or space
	- Limited space int he category or x axis, when labels are long
- Bar:
	- Costs, prices
	- Can be symmetrical about centre
	- Easier to read with long categorical label
## Pie?

# Scatter Plots
- Used to show the relationship between two variables, most accurate way to show correlations
	- Use markers of different styles for multiple types (avoid crosses)
	- Do not rely on colour
	- When multiple markers required, use open markers first
## Connecting Points on Scatter Plots
- Where numerical data is used to define points (markers) on a scatter plot, these points must remain sclear
- In general, no lines should be drawn to connect the dots, a line suggets a continuum of data

# Line Plots
- Solid lines hsould only be plotted when the data represents a model for which continuous values can be determined at every point on the plot
# Cognitive Load
- How hard the reader has to work to understand what you are trying to communicate
- High cognitive load:
	- Hard to understand
	- Hard to remember
	- Hard to communicate
- Low cognitive load:
	- Understood at a glance
	- Obvious/clear message
	- Good for most charts
- You can deliberately attempt to raise the cognitive load
	- focus on a subtle aspect
	- force readers to consider from a different point of view

# Classic Chart Errors
- Beware of autoscaled axes, axis above 1 for normalised parameters is wrong! Likewise if it cannot be negative
- Fitting data, you cannot plot an exponential if you have no model to support the equation
- Colour: must be readable in black and white
- Refering to the figur in the text of a document: figure must not appear before the first mention of the figure in the document
- Beware of symbols
- Be specific, no it, this, these
- Non-breaking space between number and units
	- When number and unit together as adjective, use -. I.e. $15-mm$ long wavelength radiation
# Data and Reports
- Figures/photos that are not your own must be attributed to a source
- All photos must be annotated to explain the photo. Figures and tables must have a caption that describes it and a table/figure number
- Avoid clutter
- Number all pages and sections
- Explain all terminology when first used
- All abbreviations must be written in full when first used
- Ensure everyone in team reads
# In-text Citations
- All statements made which are not obvious to someone skilled in the art require an in-text citation ([1] or (Smith, 1998))
- In student reports, all statements made which you did not know before starting the work and had to look up require an in-text citation
- Typically *et al.* is written in italics
# Error Bars
- Should be called uncertainty bars in this unit
- Reference must be made to:
	- Level of confidence ($P=95\%$)
	- Sample size used
	- Coverage factor k
- Error bars should be expressed in x and y directions
# Box Plots
- More information about the summary statistics can be provided by a box plot
- 1st and 3rd quartile, median and max/min values
# Median vs. Mean
- Mean is the arithmetic average of a set of numbers
	- Disdvantage of being affected by any single value being too high or too low
- Median is described as the numeric value separating the higher half of a sample or a probability distribution
	- Will differ substantially from the mean if the probability is skewed
# Percentiles
- Value below a certain percent $p$ of all observations fall
- $P(X\leq m) = p\%$
