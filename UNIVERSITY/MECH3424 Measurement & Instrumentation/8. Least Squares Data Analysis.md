The method of least squares is used to solve a set of linear equations which may contain noise, where there are more equations than unknown variables. Since there are more equations than variables, the solution will not be exactly correct for each equation; rather, the process minimizes the sum of the squares of the residual errors. The only requirement to solve the general least squares problem is that there are at least as many equations as there are unknowns
# Purpose
- Linear regression attempts to find the optimum relationship between a dependent variable $Y$ and inputs $x_i$ where the relationship is linear: $$Y=\beta_{0}+\beta_{1}x_{1}+...+\beta_{r}x_{r}+e$$
- Where the coefficients $\beta_i$ (regression coefficients) are to be found and $e$ is a zero mean random error
- Consider simple linear regression: $Y=\alpha + \beta x+e$
	- Best estimate of $Y_i$ is $E[Y_{i}|x_{i}]=E[\alpha]+E[\beta]x_{i}+E[e]$
	- $A=E[\alpha], B=E[\beta], E[e] = 0$
	- The regression coeffs $\alpha$ and $\beta$ are not known but must be estimated using A and B such the response would be given by $A+Bx_{i}$

# Various Types
- **Linear**: multiple linear regression is a form of fitting which expresses the measurand $Y$ as a linear function of the unknown parameters $\beta_{i}$ of the model *not $x_i$* 
	- As the model is a linear combination of input quantities, least-squares processes will produce a unique solution for the unknown without requiring any initial guess $$Y=\beta_{0}+\beta_{1}x_{1}+...+\beta_{r}x_{r}+e$$
	- Simple linear regression: $Y=\beta_{0}+\beta_{1}x+e$
- **Polynomial**: special case of linear regression where high orders of $x$ are used to fit a nonlinear relationship between $x$ and the measurand $Y$: $$Y=\beta_{0}+\beta_{1}x^{1}+\beta_{2}x^{2}+...+\beta_{p}x^{n}$$
	- The model remains linear as long as it is linear combination of $\beta$ 
	- The number of terms ($\beta$) to fit is $p+1$
# General Least Squares
- Consider a function which could fit our data given by the general function represented by $n$ parameters $A_{1}, ...A_{n}$ given by $$Y_{i}=f(x_{i}, A_{i})$$
- The aim of a least squares regression is to find the parameters ($A_i$) by minimising the **Numerical solvers applied to linear or non-linear least squares problem**sum of least squares residuals (SSR) given by:$$SS_{R}=\Sigma^{n}_{i=1}(Y_{i}-f(x_{i},A_{i}))^{2}$$
- Done by differentiating the SSR w.r.t. each of the parameters to give $$\frac{\delta SS_{R}}{\delta A_{i}}=-2\Sigma^{n}_{i=1}\frac{\delta f(x_{i},A_{i})}{\delta A_{i}}(y_{I}-f(x_{i},A_{i}))=0$$
- This results in $n$ equations which need to be solved in order to find the $n$ parameters. Non-linear solver are required to solve each parameter and the key requirement of these solvers is the need for an initial condition for each parameter $A^{0}_{n}$
- Note the number of parameters is important and not the order of the equation (i.e. a high order polynomial of $p$) when defining the DOF for a problem

# $R^{2}$ - Coefficient of Determination
- The sample correlation coefficient denoted by $R$ is given by: $$R=\frac{SS_{xY}}{\sqrt{SS_{YY}SS_{xx}}}$$
	- Where $R$ ranges from $-1\leq R\leq 1$ 
	- $|R|\approx 1$ suggests a good fit (but not always)
- Often an $R^{2}$ value is quoted for a linear regression. It is the coefficient of determination or the squared multiple correlation. It is the percentage of the total variation in the y-values that is explained by the regression equation. It is given by $$R^{2}=\frac{SS_{xY}^{2}}{SS_{YY}SS_{xx}}=1- \frac{SS_{R}}{SS_{y}}$$

# Resampling (Computational) Methods
- **Jack knife**: dataset with n points, construct exactly n hypothetical datasets each with n-1 points, each one omitting a different point
	- Characterising patterns and processes
	- Estimate population size and vital rates
	- Creating environmental modelling
	- For evolutionary processes and rates
	- To calculate an appropriate sample size for experimental design
	- For calculating estimator that is a simple analogue of a parameter
	- To estimate the bias and standard error in a statistic, when a random sample of observations helps calculate it
	1. Delete the first data point from point from the original data set
	2. Fit the jack knifed set to compute the fit parameters $\beta_{0}^{1}, \beta_{1}^{1},...\beta_{N}^{1}$
	3. Repeat steps 1 and 2 n-times (where n is the number of data points), deleting now point 2, 3, ... n, to obtain a set of $n\space \{\beta_{0}^{i}, \beta_{0}^{i},...\beta_{N}^{i}\}$ parameter sets
	4. Compute the jack knife estimate of the standard error of parameter $\beta = \{\beta_{j}; j = 1\space to\space N\}$ as:
		- $u(\beta_{j})=[\frac{n-1}{n}\Sigma^{n}_{i=1}(\beta^{i}-\bar{\beta})^{2}]^\frac{1}{2}$ where $\bar{\beta}=\frac{1}{n}=\Sigma^{n}_{i=1}\beta^{i}$
	- If the uncertainty on a parameter has a known distribution (for example normal or students-t), then tabulated values of the appropriate function can be used to translate standard error to level of confidence
	- Added bonus: outliers can easily be detected by analysing the sum of squares of the residuals (SSR) of jack knife sets: if deleting a data point decreases significantly the SSR of the resulting reduced set, that point is probably in error![[Pasted image 20260915121018.png]]
- **Bootstrap**: generate large number of datasets, each with n data points randomly drawn from the original data. Constraint is that each drawing is made from the entire dataset. The bootstrap can be viewed as a Monte Carlo method to simulate from an existing data, without any assumption on the underlying population
