# Uncertainty vs. Error
$$Uncertainty = doubt$$
- Estimate the amount of doubt
$$error = deviationFromAbsoluteTruth$$
- Error suggests a mistake $$error = x-\bar{x}_{true}$$
	- $x$ is the measured value and $\bar{x}_{true}$ is the true value of the mean
	- As the true value can never be known, errors cannot be known exactly
- Random component: differs from each repeat of the experiment
- Systematic component: same with each repeated experiment
### Lack of True Value of the Mean
- If you don't know where the target is, you can't get a decent estimate of the systematic error
### Populations and Samples
- Infinite or finite population
- The population is $P(X)$, population mean $\mu$, population variance $\sigma^{2}$, Greek means population, these are generally unknown
- Sample mean $\bar{x}$, sample variance $\overline{(x-\bar{x})^2}$ are important statistics

# What's a pdf, PDF and CDF
- **PDF** - probability distribution function is a function of $x$ that contains all the information necessary to compute the probability $P(E)$ for any event $E$
- $P(E)$ is the CDF 
$$F_{X}(x) = P(X\leq x)=P_{X}[(-\infty, x)]$$
- *pdf* is a continuous function $f(x) = \frac{dF_{X}x}{dt}$

# How Many Means to Average
- We want to know the expected value of the spread in the mean
- To do that we need the variance of $\bar{X}$ (the sample mean) defined as:
$$E[(\bar{X}-\mu)^{2}]=Var(\bar{X})=Var(\frac{1}{n}(X_{1}+X_{2}+...+X_{n}))$$$$=\frac{1}{n^{2}}(Var(X_{1})+Var(X_{2})+...+Var(X_{n}))$$
$$=\frac{n\sigma^{2}}{n^{2}}=\frac{\sigma^{2}}{n}$$
