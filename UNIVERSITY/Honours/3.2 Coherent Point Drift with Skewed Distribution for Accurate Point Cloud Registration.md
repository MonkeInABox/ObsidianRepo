- Point cloud registration "estimates the relative pose between two point clouds"
- Focuses on correspondence-free registration
	- Iterative Closest Point (ICP) computes point correspondences via NN, minimising sum of square residuals for the point pairs. 
	- Variants can add to accuracy and robustness using adaptive functions or geometry
	- Accuracy not great when you get less robust clouds
- Proposal of enhanced point cloud registration based on CPD (Coherent Point Drift)
	- Skewed distribution instead of gaussian
		- Gets information from local surface normals
		- Gaussian are centre symmetric
- Lots of previous ICP (iterative closest point) algorithm research
	- These demand accurate clouds

> Point cloud registration is aligning sets of points with one another with minimal distance between pairs
