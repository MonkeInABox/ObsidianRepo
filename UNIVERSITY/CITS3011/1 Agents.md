## Rational Agent
- For each possible percept sequence a rational agent should select an action that is expected to maximise its performance measure.
- An agent perceives the environment and acts accordingly
## Task Environment
- Performance, Environment, Actuators, Sensors (PEAS)
- Fully vs. Partially Observable
- Deterministic vs. Stochastic
- Episodic vs. Sequential 
- Static vs. Dynamic
- Discrete vs. Continuous
- Single-agent vs. Multi-agent

## Simple Reflex Agents
- Choose an action using condition-action rules (if-then)

## Model Based Agents
- Stored memory of the past, as an internal state
- Understanding how the world will evolve with or without actions

## Goal Based Agents
- Reacting better to the changing world, having a goal
- Predicting the future

## Utility Based Agents
- Goal is binary
- Most outcomes are more continuously measured
