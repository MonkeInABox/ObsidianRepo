- A standard interface to a processing system. 
- Provides a software framework to program machines in a standardised way
	- Easy integration of machinery because of the specification of standard vertical and horizontal interfaces to the machine allowing for a machine to be replaced by a different vendor without the need to rewrite the software. All machines meeting the standard operate in the same way
	- Reduced cost of operation resulting from reduced training
- Programming methodology based on a state transition diagram, defines 17 states and the transitions from one state to another, that do not all need to be used
- The standard has "Modes" which are used to define which states are to be incorporated in a particular mode
- Standardised tags (PackTags) describing condition
	- 3 types: Command, Status or Administration
		- Command are used to control the machine `PMLc.StateCmd.Start`
		- Status tags are used to read the status of the machine `PMLs.UnitModeCurrent, PMLs.State.Idle`
		- Administration tags are used to collect data from the machine `PMLa.Alarm[1].ID`
- Standardised hooks for data collection can be used for OEE (Overall Equipment Effectiveness) and RCA
- Items called units or machines are a collection of physical equipment and control functions that perform one or more major processing functions
	- Can be a single machine or a subset
- 17 states divided into Waiting and Acting (ends with -ing) states
```
17 States:
- STOPPED : powered and stationary after STOPPING or CLEARING
- IDLE : RESETTING complete, until STARTING
- STARTING : when a command is given, steps to start EXECUTION
- SUSPENDING : brough to controlled SUSPENDED, status saved
- SUSPENDED : once process conditions are normal moves to UNSUS
- UNSUSPENDING : transition from SUSPENDED to EXECUTE
- EXECUTE : performing the required action
- STOPPING : bring to controlled stop, until RESETTING takes place
- ABORTING : rapid safe stop
- ABORTED : only exit after a CLEAR command
- HOLDING : minor STOP
- HELD : until UNHOLD
- COMPLETING : from EXECUTE when the run is complete
- COMPLETE : until RESET
- RESETTING : transition to IDLE
- CLEARING : when cleared faults occurred when ABORTING
```
