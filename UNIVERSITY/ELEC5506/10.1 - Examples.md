# Example 1
$$(J+ML^{2})\ddot{\theta}=T(t)$$
Where $\theta$ is the angular displacement, $T$ is the motor torque, $J = 1$, $M=8$, $L=2$ 
It is proposed a PD controller be used with 
$$T(s)=K(\theta_{r}(s)-\theta(s))-K_{d}\dot\theta (s)$$

$J+ML^{2}\ddot\theta = 33\ddot\theta =T(t)$
$\frac{T(t)}{\ddot\theta} = 33 = \frac{T(s)}{s^{2}\theta(s)}$
$P(s) = \theta(s)/T(s)=1/33s^2=OLG$  
$\theta(s) = \frac{1}{33s^{2}}\times (K(\theta_{r}(s)-\theta(s))K_{d}s\theta (s))$  
$33s^{2}\theta (s) = K(\theta_{r}(s) - \theta(s))K_{d}s\theta(s) = K\theta_{r}(s)-\theta(s)(K+K_{d}s)$
$(33s^{2}+K+K_{d}s)(\theta(s))=K\theta_{r}(s)$
$\therefore G(s) = K/(33s^{2}+K+K_{d}s)$
> MAKE SURE TO REARRANGE SO THAT $s^2$ HAS NO FACTOR


Open Loop Gain = $P(s) \times G(s)$
Closed Loop Gain = $G/(1+G)$ 

$T_{s}=0.49s, T_{r}=0.12$ 
$0.49 = 4/(\frac{K_{d}}{2})$
$K_d = 16.33\times 33= 538.89$
$T_{r} =\frac{1}{\omega_{d}}tan^-1(-\frac{\sqrt{1-\zeta^2}}{\zeta})$


Small $\zeta$ is $< 0.2$
