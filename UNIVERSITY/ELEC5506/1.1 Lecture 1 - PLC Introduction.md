# PLCs
## Why use PLCs?
- Ease of reconfiguring application of sensors and actuators
- Possible to use logic conditions
- Standards to allow easy incorporation
- Rather than changing wires to chance program
- Internet connections
- Faults easy to find

> Pnemonic Code: `LD X00 OUT Y10 END`, which is what the ladder program is translated to.

- PLCs are designed to be uninterruptible
- Therefore, they are robust

### Symbols Used:
- `XIC` = Examine if Closed: determine `IF` bit is `1`, then instruction is evaluated as true
- `XIO` = Examine if Open: `IF` bit is `0`, then instruction is evaluated as true
- `OTE` = Output Energise: Turn on a bit when conditions are evaluated as true
- `OTL` and `OTU` = Output latch and Output unlatch: turns on and off a bit
- `OSR` = One-shot rising: Starts based on change of state of the rung from positive to true (occurs only on that loop)

### Logic `AND`
- The `OTE` subroutine will make the value of its memory location `1` if the value passed to it (after the subroutines on its left hand side of the rung) is `TRUE` else the memory location becomes `0`

## Design Considerations for PLC Programming
1. Understand the system specifications; be clear on what is required for inputs and outputs
2. Review possible control methods
3. Flow chart the process
4. Implement flow chart using logic diagrams or relay logic
5. Assign I/O addresses
6. Translate to PLC code
