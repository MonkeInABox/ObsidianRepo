## Proportional Control
$$u(t) = k_{p}e(t)=k_{p}(r(t)-y(t))$$
![[Pasted image 20260428091017.png]]
- Where $K$ is the constant gain
- $y(t)$ can only equal $r(t)$ if $Kk_p >> 1$ 
![[Pasted image 20260428091155.png]]
- $K = \frac{R_1}{R_1 + R_{2}}$ 
- Has the transfer function $y(t) = Ku(t)$ 
- $R_s+AR_{2}| k_{p}=A$  
#### With an Op Amp
![[Pasted image 20260428091440.png]]
- $k_p = A$, if $Kk_p >> 1$ then $y(t)$ follows $r(t)$ with minimal error
![[Pasted image 20260428091808.png]]
- As we increase $k_p$ the output becomes more and more oscillatory
	- As we increase the gain, we increase the chance of oscillation
- $\zeta$ is the damping factor
	- Decreasing $\zeta$ makes it rise faster, 1.0 is when it rises fastest without any overshoot
	- Decreasing also makes it more oscillatory
- $P(s) = \frac{1}{s^{2} + 2bs + c^{2}}$ where the denominator is the characteristic function
	- Adding proportional compensator $C(s) = k_p$ 
	- $G(s)=\frac{P(s)C(s)}{1+P(s)C(s)} = \frac{k_{p}}{s^{2}+2bs+(c^{2}+k_{p})}$ 
	- $\omega_{nc}=\sqrt{c^{2}+k_{p}}$
	- $\zeta_c = \frac{b}{\omega_{nc}}$ 
- We can add a constant to get the output equal to the input, removing the difference
	- This will only work if the system and input is unchanging - not appropriate for real life
	- We need a method of bringing the error back to zero - this is where the integral controller comes in

# PI Controller
![[Pasted image 20260428094032.png]]
$$u(t) = k_{p}e(t) + k_{i}\int ^{t}_{0}e(\tau)d\tau$$
- Output of our compensator: $u_{0}=k_{p}(e_{0}+\frac{e_{0}}{T_{i}}t)$
- $\frac{du}{dt}=k_{p}\frac{de}{dt}+k_{i}e$
- The transfer function then is: $C(s) =k_{p}+\frac{k_{i}}{s}$
