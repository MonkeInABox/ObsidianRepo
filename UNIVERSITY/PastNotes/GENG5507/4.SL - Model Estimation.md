# Model Building
- Estimation of population mean and standard deviation from a sample with censored data
- How do we know underlying distribution
	- Histogram 
	- Trial and error
	- Use statistical estimation methods (such as Maximum likelihood (MLE)), and goodness-fit tests to the estimated
# Estimation of Population Mean & Standard Deviation from a Complete Sample
$$\hat{\mu}\frac{\sum_{i=1}^{n} t_{i}}{n}, \hat{\sigma} = \sqrt{\frac{\sum_{i=1}^{n}(t_{i}-\hat{\mu})^{2}}{n-1}}$$
- For exponential and normal distribution these parameters determine the distribution, but for others we may not be able to estimate the parameters explicitly

# Types of Censoring
## Right Censoring
- Type I: Time terminated - testing is terminated after a fixed length of time $t_*$ has elapsed
- Type II: Failure terminated - testing is terminated after a fixed number of failures r, has occurred. The test time is then given by $t_r$, the failure of the $r^{th}$ failure
![[Pasted image 20260324021815.png]]
## Total Time on Test T
- It is the total operating time that all units experienced "on test"
- For complete data, r=n $$T = \sum_{i=1}^{n} t_{i}$$
- For type I censoring $$T = \sum_{i=1}^{r}t_{i}+(n-r)t_{*}$$
- For type II censoring $$T=\sum_{i=1}^{r}t_{i}+(n-r)t_{r}$$
- $r$ is the total number of failures, $n$ is the sample size
![[Pasted image 20260324022132.png]]
## Estimation of standard deviation from the sample
- To do this we must first calculate the sample mean (use all data)
$$\hat{\mu} = \frac{\sum_{i=1}^{n}t_{i}}{n}, \hat{\sigma} = \frac{\sum_{i=1}^{n}(t_{i}-\hat{\mu})^{2}}{n-2}$$
![[Pasted image 20260324022551.png]]
## Estimation of the Parameter of Exponential Failure Times
- Exponential distribution has only parameter $\lambda$ 
- When we know or given the data are from exponential distribution
- We can find the point estimate of the mean time to failure MTTF $$MTTF = \hat{\mu} = \frac{T}{r}$$
- Alternatively, the point estimate of the hazard rate $$\hat{\lambda}=\frac{r}{T}$$
	- where r is the number of failures and T is the total time on test

# Maximum Likelihood Estimation (MLE)
- Calculates the most likely value of a given parameter given the observed values and assumed distribution
- Favoured as the method for parameter estimation amongst statisticians, when data is available and a specific model type is assumed
- Often MLE may not be analytically solved for and computational methods for root finding problems such as the Newton-Raphson method are required
![[Pasted image 20260324023026.png]]
$$X_{i} \sim f(x|\theta)$$
- The likelihood is the product of $i$ PDFs in terms of the parameter $\theta$ 
$$L(\theta) = \prod_{i=1}^{n}f(x_{i}|\theta)=\prod_{i=1}^{n}L(\theta|x_{i})$$
$$l(\theta) = ln(L(\theta))$$
$$l(\theta) = \sum_{i=1}^{n}ln(f(x_{i}|\theta)) = \sum_{i=1}^{n}l(\theta |x_{i})$$
- To find the maximum likelihood function such that $$\hat{\theta}_{MLE} = argmax\space l(\theta)$$
- This is equivalent to the root finding problem where we find the roots such that $$l'(\theta) = 0$$
- Assumptions are that $l'$ exists, $l'$ is continuously differentiable and $$l''(\hat{\theta}_{MLE)}\neq 0$$

# Estimate the CDF of F
- Assume observed failure time are ordered $$t_{1}\leq t_{2} \leq ... \leq t_{n}$$
- Then to define the estimated value of F at $t_i$ $$\hat{F}(t_{i}) = \frac{i}{{n+1}}$$
![[Pasted image 20260324043709.png]]
# Alternative: Bernard's Approximation Formula
$$\hat{F}(t_{i}) = \frac{i - 0.3}{n+0.4}$$
- $i$ is the $i$th failure after sorting in ascending order
- $n$ is the total number of items (sample size)

# Kaplan-Meier Estimation
- Estimates the survival function (reliability) and hazard rates from data that may be incomplete due to censoring
$$R(t) = \frac{numberItemsSurviving>T}{totalNoTested}$$
- Suppose a sample has $n$ observations (some of them could be censored)
- $d_i$ is the number of failures at $t_i$ 
- $n_i$ is the number of items at risk just prior to $t_i$ 
- $R_n (t)$ is the K-M $R(t)$ based on sample size $n$

![[Pasted image 20260324044502.png]]

- Estimate of CDF is $F_{n}(t) = 1-R_{n}(t)$
	- Note that if $t_i$ is a censored observation and there is no failure at $t_i$ then $d_{i}=0$ and hence $\frac{n_{i}-d_{i}}{n_{i}}=1$ do not contribute anything to the product
