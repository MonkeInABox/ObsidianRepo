# Events and Probabilities
#### What are we interested in?
1. Type of failure: The list of all possible types of failures is denoted as `S` (Sample Space)
2. Probabilities of certain types of failures (Event `A` and its probability `P(A)`
3. Lifetime of a part or component, and chance of it lasting beyond a certain time (Random Variable `X` and its distribution)

# Disjoint and Exhaustive Events
- If $B_{1}$ and $B_2$ are two sets of failure types, then they are disjoint (or mutually exclusive) if:
$$B_{1} \cap B_{1}= \phi, \phi = \text{empty set}$$
- $B_{1}, B_{2}, ....$ events are exhaustive if:
$$\cup^{n}_{i=1}B_{i}=S$$
- MDE: mutually disjoint and exhaustive (partition of $S$)

# Some Properties
$$P(A\cup B) = P(A) + P(B) - P(A\cap B)$$
- For $P(B) > 0$:
$$P(A|B) = \frac{P(A\cap B)}{P(B)}$$
- If $B_{1}, B_{2}, ...$ are MDE and $A$ is any event:
$$P(A) = P(A\cap B_{1}) + P(A\cap B_{2})...$$
- If $B_{1}, B_{2}, ...$ is a partition (MDE) of $S$ with $P(B_{i})>0$ and $A$ is any event:
$$P(A) = P(A|B_{1})P(B_{1})+P(A|B_{2})P(B_{2})+...$$
- $P(A) = P(A\cap B) + P(A \cap B')$

# Independent Events
- If $P(A\cap B) = P(A)P(B)$ then the events are independent
- A given B does not change from just A

# Other Formulae
$$P(A\cap B \cap C) = P(C|B \cap A)P(B|A)P(A)$$
- **Bayes Theorem**: If all B are a partition of $S$ with $P(B_{i})>0$ and $A$ is any event then for any $j$:
$$P(B_{j}|A) = \frac{P(A|B_{j})P(B_{j})}{P(A)} = \frac{P(A|B_{j})P(B_{j})}{P(A|B_{1})P(B_{1})+ ...}$$
