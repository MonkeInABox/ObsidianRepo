# Discrete Models
## Discrete Uniform Distribution
- $X$ is uniform with values $\{x_{1},x_{2},...,x_{k}\}$ and the probability mass function: $$p(x)=\frac{1}{k}$$
- i.e. a fair die: $p(x) = 1/6$ 
- $var = \frac{b^{2}}{12}$ where $b$ is the length

## Poisson Distribution
- One can think of the number of electronic components that fail per unit of time or number of phone calls coming to a switch board per unit of time25*
- Rate of failure per unit time = $\lambda$
- $X$ = number of failures in $t$ units of time, then if $X$ has Poisson Distribution its probability mass function is:
![[Pasted image 20260310091533.png]]
- $\mu = \lambda t$
- $X\sim Poisson(\mu)$
- In general, if $X(t)$ = number of failures in t units time for $t>0$ then $X(t)$ is said to be a Poisson process with rate $\lambda$ is certain conditions hold

## Lognormal Distribution
- $T\sim LN(\mu, \sigma^2)$ 
- A nonnegative r.v. $T$ is said to have a lognormal distribution if the r..v. $X=ln(T)$ has a normal distribution
![[Pasted image 20260310092522.png]]
- Note $\mu$ and $\sigma$ are the mean and standard deviation of $X$, not $T$
- Note that $T$ does not take negative values as $X$ does

### Gamma Function $\Gamma$ 
$$\Gamma(z) = \int^{\infty}_{0}e^{-t}t^{z-1}dt$$
- If $z=n$ is positive: $\Gamma(n)=(n-1)!$ 
- Otherwise the value can be found in a table
- Also for all $z>0$: $\Gamma(z+1) = z\Gamma(z)$

## Exponential Distribution
- A special case when $\beta = 1$ in Weibull
- Important in reliability
- $f(t)=\lambda e^{-\lambda t}$
- $F(t) = 1-e^{-\lambda t}$
- $\mu = \frac{1}{\lambda}=mean$
- $\sigma = \frac{1}{\lambda}=StandardDeviation$
