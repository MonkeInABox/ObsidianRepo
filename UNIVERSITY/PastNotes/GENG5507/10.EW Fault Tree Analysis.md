# Fault Tree Analysis
- Why?
	- Determine the system logic
	- Investigate a system under development to prevent/mitigate failure causes
	- Determine a system reliability
	- To assist probabilistic risk management
A deductive, top-down method of analysis aimed at pin-pointing the cause or causes of a predefined event
- Can be qualitative or quantitative
- FTA is top down:

## Developing an FTA
1. Define the top event (undesired event)
	1. Context
2. Understand the system and logic
3. Construct the fault tree
4. Evaluate the fault tree logic
5. Treat the hazardous/failure events (if required)

# Some Notes
- There can be the same event in different spots/branches of the system
- Design intent? Speed? Capacity? Availability?
- What constitutes a failure?
- System functional structure
	- The components, LMU (lowest maintainable unit)
- System boundaries
- System operational modes
- To work out the reliability we need MBTF (so we can have $\lambda$ and run time)
- $Reliability = 1 - Unreliability -> R = 1 - Q$
- k-out-of-n is like a truss

# OR Gates
- A system that is dependent on all elements within that system to function is modelled using a series system
	- Xbox
	- Drive Train
	- Computer

# AND Gates
- A system that is dependent on at least one element working, modelled as a parallel system
	- Computer control
	- Boot release
	- Standby systems in plant
# Minimum Cut Sets
- Cutting the path of reliability to see which one causes the system to fail (the minimum cut set is the minimum number of items cut for system to fail)
# Minimum Path Sets
- All the ways that the system can work
- What is the pathway for the reliability to be successful
- Turns into a parallel system of each possible success path
# Decomposition Method
- Law of total probability
- $R_{sys}=R(Sys|C)R(C) + R(Sys|C')R(C')$ 
- $R_{sys}=R_{1}R(C) + R_{2}(1-R(C))$ 
# Event Space Method
- $2^{numberofBlocks}$
- Still have to check which ones constitute failure
	- Add those together to get $Q_{sys}$

	- Circuit Fault: 100 - $e^{-1/100} = 0.99$
- Controller
	- Loose terminal: 10 - $e^{-1/10} = 0.905$
	- Low voltage: 20 - $e^{-1/20} = 0.95$
- Battery
	- Damaged cell: 50 $e^{-1/50} = 0.98$
	- Faulty Terminal: 20 $e^{-1/20} = 0.95$
	- Flat Battery: 20 $e^{-1/20} = 0.95$
