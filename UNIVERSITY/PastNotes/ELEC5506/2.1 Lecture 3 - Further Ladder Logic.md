# Some Notes on the *Tricky Examples*
- The output gates are changed to whatever is the output on that rung
- All outputs get "shipped out" at the same time, i.e. the hardware is only changed once all rungs have been gone through
- If a switch is closed, even if the memory is changed in the rungs, on the next go through of the logic, the switch gets set as what the switch would be when its closed **it does not change the physical switch position when memory is changed**

# Tank Filling Example
- Water level is to be maintained
- When water level reaches level low, the outlet flow valve is closed and the inlet flow valve is open
- When high level is reached, the outlet valve is opened and the inlet valve is closed
- To detect high and low levels of liquid in the tank, two level switches are used

- You want to have the least rungs as possible, whilst taking into account the possible states and what would lead to those states
- How many states? 
	- Emptying, filling, start, stop
- Second rung logic: $OV = Master\bullet (HL + OV)\bullet \overline{LL}$
- Third rung logic: $IV = Master \bullet (LL + IV + Start) \bullet \overline{HL}$
- Need to identify some constraints/conditions: for example, in the answer, `LL` is treated as open when the water level is low and `HL` is closed when water level is high
- If it is a filling state, you want to keep filling, inverse for emptying
- The first rung is a latch and allows the start to become a push button, this is enabled by using memory (`%M 0/0`)

# Ladder Programs
- They are meaningless without a well defined table of input and output connections
- **START STATE**: tank filling because inlet valve is open and outlet is closed (the tank is empty)
- **BETWEEN EMPTY AND FULL**: Tank filling ladder program shown in the figure after the start button is pressed and the state of the tank is empty. The tank is filling because the inlet 0valve is open and the outlet valve is closed. 
- **FULL**: Tank filling ladder program shown in the figure when the tank becomes full. The tank will stop filling because the inlet valve is closed and the tank will begin to empty because the outlet valve is open. The tank will continue to empty until the low level switch is activated and the cycle starts again.
