# Maze Algorithm
## Follow Left Wall
``` cpp
void turn(int change, int *dir)  
	{ VWTurn(vw, change*90, ASPEED);  
	VWWait(vw);  
	*dir = (*dir+change +4) % 4;  
}  
void go_one(int *x, int *y, int dir)  
	{ switch (dir)  
		{ case 0: (*y)++; break;  
		case 1: (*x)--; break;  
		case 2: (*y)--; break;  
		case 3: (*x)++; break;  
		}  
	VWStraight(vw, DIST, SPEED);  
	VWWait(vw);  
}

void explore_left(int goal_x, int goal_y)  { 
	int x=0, y=0, dir=0; /* start position */  
	int front_open, left_open, right_open;  
		while (!(x==goal_x && y==goal_y)) /* goal not reached */{ 
		front_open = PSDGet(psd_front) > THRES;  
		left_open = PSDGet(psd_left) > THRES;  
		right_open = PSDGet(psd_right) > THRES;  
		if (left_open) turn(+1, &dir); /* turn left */  
		else if (front_open); /* drive straight*/  
		else if (right_open) turn(-1, &dir); /* turn right */  
		else turn(+2, &dir); /* dead end - back up */  
	go_one(&x,&y,dir); /* go one step in any case */  
	}  
}
```

```cpp
void explore()

	if (front_open && unmarked(rob_y,rob_x,old_dir))  
		{ go_to(old_dir); /* go 1 forward */  
		explore(); /* recursive call */  
		go_to(old_dir+2); /* go 1 back */  
		}  
	if (left_open && unmarked(rob_y,rob_x,old_dir+1))  
		{ go_to(old_dir+1); /* go 1 left */  
		explore(); /* recursive call */  
		go_to(old_dir-1); /* go 1 right */  
		}  
	if (right_open && unmarked(rob_y,rob_x,old_dir-1))  
		{ go_to(old_dir-1); /* go 1 right */  
		explore(); /* recursive call */  
		go_to(old_dir+1); /* go 1 left */  
		}  
}
```

## Flood Fill Algorithm
- Start: Mark start cell, can be reached in 0 steps
- Loop: For all cells: IF unmarked cells is neighbourhood a marked cell AND there is no wall between them THEN mark this cell it can be reached in neighbour value + 1 steps
	- Until no change

## Shortest Path
- Now we have: explored the maze, know the distance to goal from every cell
- Missing: shortest path from start to goal
- Idea: generate shortest path from goal backward to start
![[Pasted image 20260331104519.png]]
```cpp
void build_path(int i, int j)  
	{ int k;  
	for (k = map[i,j]-1; k>=0; k--)  
		{  
			if (i>0 && !wall[i][j][0] && map[i-1][j] == k)  
			{ i--; path[k] = 0; /* north */  
			}  
			else  
				if (i<MAZESIZE-1 &&!wall[i+1][j][0] &&map[i+1][j]==k) 
				{ i++; path[k] = 2; /* south */  
				}  
			else  
				if (j>0 && !wall[i][j][1] && map[i][j-1]==k)  
				{ j--; path[k] = 3; /* east */  
				}  
			else  
				if (j<MAZESIZE-1 &&!wall[i][j+1][1] &&map[i][j+1]==k) 
				{ j++; path[k] = 1; /* west */  
				}  
			else  
			{ LCDPutString("ERROR¥a");  
			}  
	}  
}
```

# Mapping General Environments
- Mapping an unknown environment is similar to the maze problem
- Should not use maze simplifications of fixed size calls and 90 angles
- Use of LiDAR sensor
- Drive a collision free course of left-hand following or use DistBug
- Enter sensor measurement data into map
