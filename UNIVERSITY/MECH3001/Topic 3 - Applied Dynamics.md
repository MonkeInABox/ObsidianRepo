# Generalised Coordinates
- Geometrically admissible motions denote a spatial configuration that is always kinematically compatible with the problem statement
- Variables that locate dynamic systems with respect to a reference frame
- Complete when it is capable of locating all parts of the system at all times
- For example if we just need x and y:
	- $\xi_{j}: x, y$ where x and y are the Cartesian coordinates of ... along the `X` and `Y` axes, with respect to the `OXYZ` reference frame
# Independence
- A set of generalised coordinates are independent if, when all but one of the generalised coordinates are fixed, there remains a continuous range of values for that one coordinate
# Admissible Variations, Degrees of Freedom, Geometric Constraints and Holonomicity
- An admissible variation of a generalised coordinate is a hypothetical contemporaneous change from one geometrically allowable state to a neighbouring geometrically allowable state
- A set of admissible variations is complete if it is capable of representing all the geometric variations of the system at all times 
- Independent if when all but one of the admissible variations are fixed, there remains a continuous range of values for that one admissible variation
- The number of independent admissible variations in a complete set of admissible variations is the number of degrees of freedom
- A geometric constraint is any requirement that reduces the number of degrees of freedom
	- Like restricting to just the $x,y$ planes
- If a number of generalised coordinates in a complete and independent set is equal to the number of degrees of freedom, the system is said to be holonomic, else it is nonholonomic
	- There is also piece-wise holonomic
# Variational Principles in Mechanics
- Natural states are geometrically admissible states that also correspond to one of the following:
	- Statics: $\sum f = 0, \sum \tau = 0$
	- Dynamics: $\sum f = \frac{dp}{dt}, \sum \tau = \frac{dh}{dt}$
